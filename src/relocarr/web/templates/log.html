Every action here only ever grabs a release that's genuinely smaller than the current file -- if nothing smaller turns up, nothing is downloaded. "Redownload" deletes a file Radarr still tracks and replaces it. "Re-monitor & search" is for a movie relocarr (or you) already finished with -- Radarr lost track of the file, so there's nothing to delete, just a fresh search. "Add & search" is for a file Radarr has never heard of -- it looks the title up and adds it, same as Radarr's own Add New screen. A quality profile picked here (or left blank to keep the current one) narrows which releases are even considered -- see Settings → Quality → Quality Definitions in Radarr for the size caps a profile's qualities carry. Once a smaller file lands, any old larger file sharing the same title/year gets removed automatically. Rows with an unparseable filename have no checkbox -- there's nothing reliable to act on.
